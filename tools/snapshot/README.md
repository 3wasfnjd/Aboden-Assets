# صور معاينة للأصول

يرسم كل أصل بدون أي مكتبة (WebGL مباشرة) ويجمع الصور في لوحة واحدة لمراجعة الشكل قبل الرفع.

    python3 tools/snapshot/snap.py JOBS out.png 3

JOBS قائمة JSON، كل عنصر: [الأصل, الجودة, إعدادات, كاميرا, عنوان]
مثال: [["sidr","med",{},{},"sidr"]]

يحتاج Playwright + Chromium (مسار المتصفح في المتغير CHROME إن لزم).
