# مستودع أصول عبودين قيمز · Aboden Assets

أصول ثلاثية الأبعاد سعودية وخليجية **مبنية بالكود بالكامل** — بدون ملفات موديلات.
كل أصل مولّد يأخذ إعدادات (طول، كثافة، بذرة…) ويُخرج الشكل، فتقدر تصنع منه أشكالاً لا نهائية.

## المعرض
صفحة `index.html` فيها سبعة مشاهد: الحي النجدي (مسوّر ببوابة ومسجد وبستان ومجلس قهوة)، السوق (شارع دكاكين وأكشاك ببائعين وركن قهوة وساحة دواب)، البادية (بيت شعر وخيام وإبل وغنم)، الكائنات، المركبات (طريق صحراوي)، واحة النباتات، وقطع العمارة. فيه نهار/مغرب/ليل: في الليل تضيء الفوانيس والوجار. اختر أصلاً، عدّله، وشاهد عدد المثلثات وأوامر الرسم.

الأصول المضيئة تعطي `meta.light` (مكان الضوء ولونه وشدته) ليضيف المحرك ضوءاً نقطياً، والمواد المضيئة فيها `emissive`.

## طريقة البناء
```
core/math.js          رياضيات + عشوائية ثابتة (نفس البذرة = نفس الشكل)
core/builder.js       أداة البناء المحايدة: نقاط، ألوان، مثلثات، أوزان الرياح
core/tree.js          مولّد الشجرة المتفرعة العام
core/texture.js       خامات بالكود: لياسة طين وطوب، أعلى الجدار، جص، خشب، باب نجدي، رمل، فخار، سجاد، سدو…
core/mud.js           جدار طين بفتحات حقيقية، كتلة طين، فتحات تهوية، صناديق
core/skeleton.js      هيكل عظمي، أوزان الجلد، مقاطع الحركة، جسم عضوي (loft)، ووضعية بالمعالج
plants/*.js           مولّد لكل نبتة
core/viewer-three.js  طبقة العرض للمتصفح فقط (Three.js) + الرياح في كرت الشاشة
tests/run-tests.js    اختبارات آلية
```

**المولّدات لا تعرف أي محرك.** كل مولّد يُخرج بيانات خام:

| الحقل | المعنى |
|---|---|
| `positions` | النقاط بالمتر، Y للأعلى، الأصل عند القاعدة على الأرض |
| `normals` | المتعامدات (محسوبة بالكود) |
| `colors` | ألوان sRGB بين 0 و 1 |
| `indices` | المثلثات |
| `sway` / `phase` / `flutter` / `bend` | أوزان الرياح: تمايل الفروع، الطور، رفرفة الورق، انحناء الجذع |
| `uvs` | إحداثيات الخامة |
| `material` | `kind` و `roughness` و `doubleSided`، و`texture` (اسم خامة من core/texture.js) أو `color` |
| `meta.collider` | شكل التصادم للفيزياء (أسطوانة/كرة/كبسولة/بدون) |
| `skinIndex` / `skinWeight` | ربط كل نقطة بأربع عظام (للكائنات) |
| `skeleton` / `clips` | العظام بوضع الراحة، ومقاطع الحركة كدورانات لكل عظمة + إزاحة الجذر |

لنقل أصل إلى محرك: نترجم ملف المولّد + `core/` إلى لغة المحرك (GDScript / Luau)، ونكتب طبقة عرض رقيقة مقابلة لـ `viewer-three.js`.

## استخدام أصل
```js
const palm = AA.assets.palm;
const params = AA.params(palm, { height: 9, bunches: 3, seed: 42 });
const out = palm.generate(params, 'med');   // 'high' | 'med' | 'low'
// out.parts.wood / leaves / fruit  →  بيانات جاهزة للمحرك
```

## حزمة لو-بولي (`lowpoly/`)

نسخة كاملة من المستودع بأسلوب لو-بولي: أوجه مسطّحة، لون لكل مثلث من لوحة مشتركة (`AA.lp.PAL`)، بلا خامات (عدا نقشة الشماغ الدقيقة)، وعدد مثلثات قليل. الشخصيات تشيبي (رأس كبير).

- كل أصل واقعي `X` له نظير `lp_X` **بنفس المعاملات والقوالب والحركات ونقاط الربط** (الأبواب، العجلات، المقاعد، الضوء، الدابة، الركّاب)، لذلك نفس المشاهد تشتغل على الحزمتين.
- المعاملات تُنسخ آلياً من الحزمة الواقعية إلى `lowpoly/lp-schemas.js` بالأمر `node tools/make-lp-schemas.js`، وكل أصل يُسجَّل بـ `AA.lp.def('X', generate)`.
- الملفات: `lp-core.js` (الأدوات)، `lp-plants.js`، `lp-terrain.js`، `lp-architecture.js`، `lp-characters.js` (مولّد شخصيات واحد بمقاسات مختلفة)، `lp-animals.js`، `lp-souq.js`، `lp-majlis.js`، `lp-vehicles.js`، `lp-badia.js`.
- المعرض: `lowpoly/index.html` يُولَّد بـ `python3 tools/make-lowpoly-gallery.py` ويستخدم مشاهد المعرض الواقعي نفسها مع استبدال كل أصل بنظيره.

## الاختبارات
`node tests/run-tests.js` — يبني كل أصل بكل جودة وكل قالب، ويتأكد أن:
الأرقام سليمة، الفهارس داخل الحدود، لا شيء ينزل تحت الأرض، نفس البذرة تعطي نفس الشكل، وعدد المثلثات ضمن الميزانية
(عالية ≤ 90 ألف، متوسطة ≤ 40 ألف، خفيفة ≤ 15 ألف لكل أصل).

> نجاح الاختبار يعني أن الحسابات سليمة — لا يعني أن الشكل جميل أو أنه يعمل داخل لعبة. هذا يُتأكد منه بالنظر والتجربة.
