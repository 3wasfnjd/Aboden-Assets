# مستودع أصول عبودين قيمز · Aboden Assets

أصول ثلاثية الأبعاد سعودية وخليجية **مبنية بالكود بالكامل** — بدون ملفات موديلات.
كل أصل مولّد يأخذ إعدادات (طول، كثافة، بذرة…) ويُخرج الشكل، فتقدر تصنع منه أشكالاً لا نهائية.

## المعرض
صفحة `index.html` تجمع كل الأصول في مشهد واحد (واحة النباتات حالياً): اختر أصلاً، عدّله، وشاهد عدد المثلثات وأوامر الرسم.

## الفئات

| المجلد | الفئة | الحالة |
|---|---|---|
| `plants/` | نباتات: نخلة، فسيلة، سدرة، طلحة، أثلة، عرفج، ثمام | ✅ الدفعة الأولى |
| `architecture/` | عمارة: بيت طين نجدي، روشان حجازي، أبواب، أسوار | قادم |
| `majlis/` | مجلس: دلة، فناجيل، مبخرة، مساند، سجاد | قادم |
| `souq/` | سوق: بسطات، أكياس بهارات، صناديق تمر | قادم |
| `animals/` | حيوانات: جمل، صقر، خيل عربي، ماعز | قادم |
| `vehicles/` | مركبات: جيب صحراوي، وانيت | قادم |
| `characters/` | شخصيات: ثوب وشماغ، عباية | قادم |
| `terrain/` | بيئة: رمل، كثبان، صخور، واحة | قادم |

## طريقة البناء
```
core/math.js          رياضيات + عشوائية ثابتة (نفس البذرة = نفس الشكل)
core/builder.js       أداة البناء المحايدة: نقاط، ألوان، مثلثات، أوزان الرياح
core/tree.js          مولّد الشجرة المتفرعة العام
plants/*.js           مولّد لكل نبتة
core/viewer-three.js  طبقة العرض للمتصفح فقط (Three.js) + الرياح في كرت الشاشة
tests/run-tests.js    اختبارات آلية
```

**المولّدات لا تعرف أي محرك.** كل مولّد يُخرج بيانات خام:

| الحقل | المعنى |
|---|---|
| `positions` | النقاط بالمتر، Y للأعلى، الأصل عند القاعدة على الأرض |
| `normals` | المتعامدات (محسوبة بالكود) |
| `colors` | ألوان sRGB بين 0 و 1 |
| `indices` | المثلثات |
| `sway` / `phase` / `flutter` / `bend` | أوزان الرياح: تمايل الفروع، الطور، رفرفة الورق، انحناء الجذع |
| `material` | `kind` (bark/leaf/fruit/flower) و `roughness` و `doubleSided` |
| `meta.collider` | شكل التصادم للفيزياء (أسطوانة/كرة/بدون) |

لنقل أصل إلى محرك: نترجم ملف المولّد + `core/` إلى لغة المحرك (GDScript / Luau)، ونكتب طبقة عرض رقيقة مقابلة لـ `viewer-three.js`.

## استخدام أصل
```js
const palm = AA.assets.palm;
const params = AA.params(palm, { height: 9, bunches: 3, seed: 42 });
const out = palm.generate(params, 'med');   // 'high' | 'med' | 'low'
// out.parts.wood / leaves / fruit  →  بيانات جاهزة للمحرك
```

## الاختبارات
`node tests/run-tests.js` — يبني كل أصل بكل جودة وكل قالب، ويتأكد أن:
الأرقام سليمة، الفهارس داخل الحدود، لا شيء ينزل تحت الأرض، نفس البذرة تعطي نفس الشكل، وعدد المثلثات ضمن الميزانية
(عالية ≤ 90 ألف، متوسطة ≤ 40 ألف، خفيفة ≤ 15 ألف لكل أصل).

> نجاح الاختبار يعني أن الحسابات سليمة — لا يعني أن الشكل جميل أو أنه يعمل داخل لعبة. هذا يُتأكد منه بالنظر والتجربة.
